# What Ask My Docs is

Ask My Docs is a small app that answers questions using a local folder of documents.

v1 goals:

- Point the app at markdown files in `docs/`.
- Ask a question in the chat box.
- Get an answer grounded in those files, with source filenames.
- If the answer is not in the files, the app should say it does not know.

It is a learning project for AI engineering: retrieval, prompting, citations, and evals — not training a model.
